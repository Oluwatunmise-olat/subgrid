# Contributing

Issues and PRs are welcome. Open an issue first for anything nontrivial,
keep changes scoped, and make sure `bunx tsc --noEmit -p .` stays clean.

See [`docs/concepts.md`](docs/concepts.md) for how the pieces fit together
and [`docs/examples.md`](docs/examples.md) for worked examples of adding a
bridge preset or a catalog integration.
